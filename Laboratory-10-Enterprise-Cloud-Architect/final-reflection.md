# Final Reflection: The Journey to Enterprise Cloud Architect

Looking back from Mission 1 to Mission 10, my journey in Cloud Computing has been transformative. From typing basic Linux commands as a Junior Trainee to deploying a fully automated, secure, multi-tier infrastructure, I have gained immense practical knowledge.

**Key Learnings:**
*   **Linux & Virtualization:** I learned how to provision headless VMs and navigate the terminal with confidence.
*   **Docker & Containers:** Understanding how to link a web server to a database using Docker Compose was challenging but highly rewarding.
*   **Security:** Hardening the server using UFW taught me the importance of closing unnecessary ports to prevent unauthorized access.
*   **Automation:** Writing a Bash script and automating it via Cron showed me how servers can manage themselves.

**Challenges Faced:**
One of the biggest challenges I faced was configuring the networking and ensuring the database was properly persisting data. However, by reading documentation and troubleshooting, I was able to overcome it. 

**Conclusion:**
I am no longer just following tutorials; I am now writing the manual. This mission has given me the confidence to design, deploy, and defend real-world cloud infrastructure.
